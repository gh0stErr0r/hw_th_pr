# hw_th_pr

`genc` — консольная программа для шифрования файла по паролю. Поддерживает Linux и macOS. Требуется Go 1.27.4 или новее.

## Сборка и запуск

```sh
make build
./genc encrypt -in a.txt -out a.genc
./genc decrypt -in a.genc -out b.txt
cmp a.txt b.txt
```

При шифровании программа просит ввести пароль дважды, при расшифровании — один раз. Ввод работает только с терминала, без отображения символов. Для замены существующего выходного файла нужен `-force`. При неверном пароле или повреждённом контейнере программа завершится с кодом 1 и не запишет результат.

Argon2id выводит ключ из пароля и случайной соли. ChaCha20-Poly1305 защищает данные и заголовок контейнера. Файл шифруется побайтово, в том числе пустой. Контейнер на 55 байт больше исходного файла.

## Ограничения

Исходный файл может занимать до 1 ГиБ. Файл и результат целиком помещаются в оперативной памяти одновременно. Argon2id выделяет отдельную память. От стойкости пароля зависит устойчивость к перебору.

Запись без `-force` требует поддержки жёстких ссылок в выходном каталоге. Права выходного файла ограничены `0600`.

## Проверки и отчёт

```sh
gofmt -l .
make vet test fuzz
```

Тесты запускаются с детектором гонок и отдельно с `GOEXPERIMENT=runtimesecret`. Экспериментальная очистка памяти действует на Linux amd64 и arm64. В обычной сборке и на macOS программа явно очищает буферы с паролями и ключом.

Готовый отчёт хранится в [docs/report/main.pdf](docs/report/main.pdf). Команда пересборки из корня репозитория:

```sh
typst compile --root . docs/report/main.typ docs/report/main.pdf
```

Уточнения к первоначальным схемам описаны в [docs/DECISIONS.md](docs/DECISIONS.md).
