# Уточнения к первоначальной версии отчёта

- Лимит открытого текста составляет 1 ГиБ. Лимит контейнера больше на 55 байт, чтобы расшифровать результат шифрования файла предельного размера.
- В первоначальных схемах готовый временный файл публиковался через `rename`. Реализация использует `rename` с `-force`. Без флага операция `link` атомарно публикует готовый временный файл и отказывает, если целевой путь занят. После публикации временное имя удаляется.
- В первоначальных схемах очистка секретов была показана на успешной ветке после записи. Реализация очищает ключ при выходе из криптографической операции, а пароль — до записи результата. Отложенные вызовы обеспечивают очистку и при ошибке. На macOS `runtime/secret.Do` вызывает переданную функцию без экспериментального стирания памяти.
- Ограничение зависимостей применяется к прямым импортам. `golang.org/x/sys` входит в граф транзитивно через `golang.org/x/crypto` и `golang.org/x/term`.
